# Wonderwood — What Happened Here?

Mobile-first playable prototype, case 01: The Missing Golden Pie. This GitHub version has lightweight SVG scene art as a temporary substitute for the higher-resolution local WebP art; the full artwork is preserved in the v0.6 handover package. Deploy with Cloudflare Pages Git integration: production branch `main`, framework None, no build command, output directory `/`.

Current testing status: code deployed to repository; Safari gameplay and Cloudflare deployment not yet verified.
